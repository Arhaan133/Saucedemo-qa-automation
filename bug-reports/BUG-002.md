# BUG-002: Locked-out user error message lacks guidance for resolution

|---|---|

| **Priority** | Low |

## Summary
When `locked_out_user` attempts to log in, the error message states the user
has been locked out but gives no next step (e.g., contact support, reset
link). This is a UX/content gap rather than a functional defect.

## Steps to Reproduce
1. Go to the login page.
2. Enter username: `locked_out_user`, password: `secret_sauce`.
3. Click Login.

## Expected Result
Error message should either link to a support/reset flow or explain why the
account was locked, per standard UX guidance for account-lockout states.

## Actual Result
Generic message: "Epic sadface: Sorry, this user has been locked out."

## Severity Justification
Functionality correctly blocks access (security requirement met); this is
purely a usability/content improvement, hence Low severity.
