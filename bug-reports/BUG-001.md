## Summary
On the checkout overview page, if a user navigates back to the cart, changes
the quantity of an item, and returns to checkout, the Subtotal/Tax/Total
values are not refreshed until the page is manually reloaded.

## Steps to Reproduce
1. Log in as `standard_user`.
2. Add "Sauce Labs Backpack" to the cart.
3. Proceed to Checkout → fill customer info → reach the overview screen. Note the Total.
4. Navigate back to the Cart page and add a second item.
5. Return to the checkout overview screen.

## Expected Result
Subtotal, Tax, and Total should reflect both items immediately.

## Actual Result
Totals still reflect only the first item until the page is refreshed.
